# DoIt — Master Your Day

A beautiful, distraction-free task management app built with Flutter.

[Download APK](#installation) • [Features](#features) • [Screenshots](#screenshots)

---

## About

DoIt is a minimalist task management app designed to help you focus on what matters. With intuitive task creation, daily scheduling, and progress tracking, it provides a peaceful environment for productivity.

## Features

- ✅ **Task Management** — Create, organize, and complete tasks with satisfying interactions
- 📅 **Daily Schedules** — Plan your day with times, reminders, and focused work sessions
- 🌙 **Dark/Light Modes** — Beautiful interface that adapts to your environment
- 📈 **Progress Tracking** — Visualize productivity streaks and stay motivated
- ⚡ **Instant Sync** — Everything saves instantly — focus on your work

## Tech Stack

- **Mobile**: Flutter (Dart)
- **Website**: React + TypeScript + Vite
- **Storage**: SQLite (local)

## Run the Website Locally

**Prerequisites:** Node.js

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The website will be available at `http://localhost:5173`

## Build the Android App

**Prerequisites:** Flutter SDK

```bash
# Navigate to Flutter project
cd ../doit

# Get dependencies
flutter pub get

# Build debug APK
flutter build apk --debug
```
